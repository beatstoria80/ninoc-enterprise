# THE NINOC ARCHIVE MANIFESTO (IDENTITY GUIDE)

## 1. CORE VISUAL IDENTITY
- **ESTETIKA**: Archival Studio, Industrial Minimalist, High-Density.
- **TYPOGRAPHY**: 
  - **MUTLAK**: Hapus semua `bold`, `black`, atau `extrabold`.
  - **STANDAR**: Gunakan `font-medium` (dan `font-display font-medium italic` untuk heading).
  - **UKURAN**: Gunakan "Tiny-Scale" (8px - 10px) untuk label & metadata, namun kontras harus tinggi.
- **WARNA**: 
  - Latar Belakang: Putih Bersih/Cream (#FFFFFF).
  - Teks: Ink (#141414) dengan kontras tinggi.
  - Aksen: Rose (#E8527A) hanya untuk elemen kritis/fokus.

## 2. TERMINOLOGI & BRAND VOICE
- **Haramkan Jargon IT**: Jangan gunakan "System", "Metadata", "Interface", "Database", "Archive System".
- **Gunakan Studio Archive**: Gunakan "Origin Specification", "Garment Archive", "Investment", "Studio Exit", "Archival Catalog".
- **Tone**: Formal, Berwibawa, Teknis-Arsip.

## 3. UI/UX ARCHITECTURE
- **COMPACTNESS**: Desain harus "Single-Screen". Hindari whitespace berlebih antar field.
- **CELL-BLOCK**: Gunakan grid rapat tanpa gap antar box input.
- **SHARPNESS**: Semua elemen harus tajam (high-contrast). Kurangi blur pada efek glassmorphism agar informasi tidak berbayang.
- **EXIT STRATEGY**: "Exit Checkout" harus statis di top-nav, bertajuk "Return to Archive Catalog".

## 4. COMPONENT RULES
- **SUPPORT CHAT**: Harus "mungil" (300px x 480px). Icon trigger harus mikro (14px).
- **CHECKOUT**: Harus kompak, satu halaman, tanpa scrolling. Field data harus rapat.

---
*Follow this manifesto strictly. Do not deviate from these rules under any circumstances. NINOC is an archive, not a generic e-commerce app.*
